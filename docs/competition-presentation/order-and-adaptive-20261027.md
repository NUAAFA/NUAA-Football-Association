# 赛事展示顺序与数量自适应

基于 `origin/main` 的 `19d1687`，在 `codex/competition-order-adaptive` 中完成。当前仅在本地隔离数据库和预览服务验收，未合并、推送或部署，也未更改生产数据。

## 展示规则

- 官网首页“当前赛事，一览即达”、首页“关注当前赛事，也重温完整赛季”和赛事中心统一使用 `Competition.publicOrder`，数字越小越靠前；同序号按年份从新到旧、创建时间、ID 确定顺序。
- 下一场开球时间只更新比赛预告，不再改变赛事卡片的先后顺序。
- “首页优先入选”只控制首页最多三项赛事的入选名额；未满三项时自动补入其他已公开、未结束、非测试赛事。入选后按统一的公开顺序展示。
- 草稿、测试赛事不公开，已结束赛事不占首页位置；赛事中心保留已公开的完整目录。

## 后台操作

在“赛事管理 → 编辑资料 → 公开状态”直接设置“公开展示顺序”。该设置从原来的折叠高级设置移到可见区域，说明明确覆盖三个展示位置。赛事列表显示排序数字与首页优先入选状态；赛事工作台显示当前是否入选首页及具体第几位。

下学期新建赛事时，可继续使用男子 20、女子 30 的顺序。应将已结束的上学期赛事状态设为“已结束”，以释放首页位置；不需要切换页面模板。“首页优先入选”是名额优先级，取消勾选并不下架赛事。

## 数量自适应

- 三项：首页上方和赛事中心桌面三列；首页下方为一张重点卡片加两张次级卡片。
- 两项：首页上方和赛事中心桌面两列；首页下方为重点卡片加一张扩展卡片，补充简介与下一场安排，重点卡片缩小标题字号以容纳较长的联赛名称。
- 一项：单列占满可用宽度；没有赛事时显示空状态。
- 手机按顺序纵向排列；平板根据可用宽度换行。

修复了首页下方次级列表固定预留三行的问题，改为只生成实际存在的行；平板列数同样按现有卡片数量适配。
