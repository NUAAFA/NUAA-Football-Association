## 展示与维护规则

1. `/media` 每篇已公开的赛事新闻/公告形成一个相册，以报道 ID 标识。目录每页最多六组，默认最近有资料的年份，可筛选年份、赛事和标题/校区。
2. 相册详情位于 `/media/albums/[id]`，显示该报道全部可公开的图片，来源及报道链接集中展示。公开封面优先；重复引用的同一张照片在该相册只出现一次。不同报道可以引用同一张照片。
3. 草稿、撤回、未来发布、未公开赛事、测试赛事、私有图片及 PDF 均不会进入报道相册。撤回报道后，其相册直接地址也不可访问。
4. 原有男子杯赛 24 张、女子杯赛 16 张照片作为两组独立赛事影像完整保留。没有确定报道归属的旧照片继续放在原赛事影像中，不推测或伪造报道归属。在数据库模式下不恢复已退役的静态报道链接。
5. `/competitions/history` 默认只展示最近有资料的年份；各年度及“全部年份”均每页最多六项，可按赛制与名称/场地筛选。
6. 原有两份完整专题继续使用原详情地址；原有六项历史记录改为 `/competitions/history/[id]` 独立展示，全部名次、赛果、裁判、日期与备注保持原值。
7. 后台标记已完成、公开且非测试的新增赛事进入年度目录，标记为“赛事记录”。原有完整专题与历史记录分别标注“完整档案”“历史记录”。同一详情地址不会重复出现。
8. 赛事中心只展示最多三个近期档案入口，始终提供全部历届赛事入口。已完成的数据库赛事集中在档案区域。
